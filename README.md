# 메디체크 AI v1.7.1 — 제조사 인식·어르신 제품 확인 개선

## 이번 버전의 핵심

**사진 올리기 → 검사하기 → 업체명·역할 확인 → 식약처 공식 후보 1개 추천(가능할 때) → 사용자 최종 확인 → 기능성 문구 예비 비교**

v1.7의 사진 1회 분석, 식약처 조회, 위험 문구 탐지, 큰 글씨/한국어 음성 안내, Streamlit Secrets 사용을 유지합니다.

### 변경 내용

- **`vision.py`**: Gemini에 제조원, 판매원, '제조 및 판매원'을 구별하고 각각 실제 사진 원문 근거와 함께 추출하도록 지시. 보고번호도 실제 OCR 원문에 명시되어야 사용합니다.
- **`company_identity.py` (신규)**: OCR 원문에서 `제조원`, `제조사`, `판매원`, `제조 및 판매원` 등 회사 역할이 명시된 문구를 검사. 판매원 단독은 절대 제조사로 승격하지 않음. 제조사·복합 역할을 혼동하지 않도록 검증.
- **`workflow.py`**: 제품 후보 중 신고번호 또는 제품명+확인된 제조업체가 **유일하게** 강하게 일치할 때만 우선 추천. 추천은 공식 확정이 아니며 사용자의 최종 확인이 필요.
- **`app.py`**: 유력 후보가 있을 때는 6개 목록 대신 **'이 제품이 맞아요 / 아니에요'**를 먼저 보여줌. 제조업체 확인이 필요할 때는 짧은 입력 양식을 바로 표시하고, 공식 조회 후보가 그대로 있으면 API를 다시 호출하지 않음. 기존 수정·상세보기 유지.
- **`tests/test_company_identity_v171.py` (신규)**: 제조·판매 역할 혼동, 근거 없는 업체명, 중복 후보, 판정 보류, 신고번호 환각, 위험광고 경고 등 안전성 검증.

## 예시: 관절팔팔

이미지에 **`제조 및 판매원 (주)씨스팡`**이 실제 글자로 읽히면, 모델의 이름 추측과 무관하게 출처 문구에서 `제조 및 판매원` 역할과 `(주)씨스팡`을 확인합니다. 식약처 I0030에 이름·업체명이 일치하는 후보가 **유일**하다면 그 후보를 먼저 표시하되, 사용자가 동일 상품임을 확인하기 전에는 초록색 부합 결과를 내지 않습니다.

이미지에 **`판매원 (주)씨스팡`만** 쓰여 있으면 제조사 일치로 취급하지 않습니다. 업체명·역할을 사용자가 직접 확인하거나 제조업체 표기를 다시 확인하도록 안내합니다.

## 파일 구성

- `app.py` — 어르신용 화면 및 결과 표시
- `vision.py` — Gemini 사진 읽기
- `company_identity.py` — OCR 업체명·역할 증거 검사 **[신규]**
- `workflow.py` — 자동 조회와 후보 추천
- `match_utils.py`, `engine.py`, `claim_filter.py`, `senior_ui.py`, `rate_limit.py` — 기존 기능 유지
- `tests/` — 외부 API 미호출 단위 테스트

## 중요 한계

- OCR 원문은 Gemini가 생성한 전사 결과입니다. 원문과 업체명 일치는 사진의 실제 표시를 **독립적으로 증명하지 않습니다**. 최종적으로 사람의 제품 동일성 확인이 필요합니다.
- 제조사 인식 정확도 향상은 실제 제품 사진 여러 장으로 비교 측정해야 입증할 수 있습니다. 이 코드의 통과 테스트 수가 인식 정확도 90% 이상을 뜻하지 않습니다.
- 건강기능식품 I0030만 지원하며 일반 식품·의약품의 적법성, 치료 효능, 복용 안전성은 확정하지 않습니다.
- 구매나 처방약 중단 여부를 이 결과만으로 결정하지 마세요.
- 공개 앱은 Gemini API 사용량/비용이 발생할 수 있으므로 제공자별 할당량과 예산을 관리해야 합니다.
